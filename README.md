# PayCalculator Nigeria 🇳🇬

A lightweight, responsive web application built to help Nigerian small business owners, HR managers, and remote workers instantly calculate monthly net take-home pay, employee pension deductions, and estimated PAYE income tax.

HTML5
CSS3
JavaScript

## 🚀 Features

* **Gross Income Calculation:** Automatically aggregates basic salary, housing, and transport allowances.
* **Pension Deduction:** Computes the standard 8% employee pension contribution.
* **Estimated PAYE Tax:** Uses a simplified progressive tax bracket calculation tailored for Nigerian income structures.
* **Copy Summary:** Instantly copies the full financial breakdown to your clipboard with one click.
* **Print / Export to PDF:** Formats the calculation results cleanly so you can print or save it directly as a PDF.
* **Fully Responsive:** Optimized for mobile phones, tablets, and desktop screens.

## 🛠️ Built With

* **HTML5** (Semantic structure)
* **CSS3** (Flexbox, Grid, custom styling, media queries)
* **Vanilla JavaScript** (DOM manipulation, event handling, clipboard API)
